# 第 2 章：从文字到训练样本

建议先打开 [chapter02.ipynb](chapter02.ipynb)，再读 [data.py](data.py)。

1. **分词**：`simple_tokenize` 用正则表达式把标点和单词分开。这只是教学版本；它会丢失空格，词表以外的词会变成 `<|unk|>`。
2. **词表**：`build_vocab` 给每个 token 一个整数编号，并加入 `<|endoftext|>`、`<|unk|>`。反向词表可以把编号查回 token。
3. **BPE**：`tiktoken` 的 `gpt2` 编码能把未见过的词拆成更小的部分，也能处理中文。token 不一定是完整单词。
4. **滑动窗口**：输入 `[a,b,c,d]` 对应目标 `[b,c,d,e]`。一次窗口里有 4 个位置，也就有 4 个「预测下一个 token」的监督信号。
5. **embedding**：词表大小为 `V`、向量维度为 `D` 时，词向量表有 `V×D` 个可训练数。长度为 `L` 的可学习位置表有 `L×D` 个可训练数。两张表查出的向量最后一维都是 `D`，才能逐项相加。

`max_length` 是一个训练样本中的 token 数，不必等于模型位置表的总长度 `context_length`；但不能超过它。第 4 章会把这两张表放入完整 GPT 模型。
